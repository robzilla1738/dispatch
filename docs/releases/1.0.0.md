# Dispatch 1.0.0

Initial signed and notarized release of **Dispatch** for macOS:

- **Native Spotlight + Aside UI**: Floating capsule search bar with inline completion badges (`Finder.app — Open`), scope chips, and a smooth slide-out Aside drawer inside the same window for Actions, AI Agent Chat, and Clipboard Preview.
- **Auto-Detected Coding Tools**: Automatically discovers installed local coding CLIs (`Claude Code`, `OpenAI Codex`, `OpenCode`, `Cursor Agent`, `Grok Build`, `Pi Agent`, `Antigravity`, `Muse Code`, `Gemini CLI`, `Aider`, `Ollama`), local `SKILL.md` skills, and MCP servers.
- **Live Model & Reasoning Effort Switching**: Switch coding providers, models, and reasoning effort (`Low`, `Medium`, `High`) right from the search bar, Aside drawer, or Settings.
- **Composio App Connectors**: 18 pre-bundled SaaS connectors with official brand icons plus one-click **Add Custom Connector** for any of 250+ Composio toolkits by slug.
- **Full Desktop Command Suite**: 27 Window Management layouts, Global Background Snippet Auto-Expansion (`;keyword`, `!keyword`, `:keyword:`), Clipboard History with Preview Pane, Floating Notes, Confetti, Calculator & Unit Conversions, Quicklinks, Emoji Search, System Controls, and Local Script Extensions.
- **Signed & Notarized Sparkle Updates**: Embedded Sparkle 2.10.0 updater (`Dispatch → Check for Updates…`) verified with Ed25519 signatures.
